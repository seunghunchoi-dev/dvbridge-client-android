```
DVBridge 클라이언트

**간단한 설명** (80자 이내)
```
DVBridge 서버에 붙어 DMR 무전을 듣고 말하는 아마추어 무선용 앱. 큰 글씨·큰 버튼.
```

**자세한 설명** (4000자 이내)
```
DVBridge 클라이언트는 아마추어 무선 DMR 중계 서버 "DVBridge"에 접속해
BrandMeister 등 DMR 네트워크의 무전을 듣고 말하는 앱입니다.

■ 이런 분께
· DVBridge 서버를 운영하는 클럽·개인의 회원
· 무전기 대신 휴대폰으로 DMR 무전에 참여하고 싶은 아마추어 무선사

■ 주요 기능
· 크게 누르고 말하기 (누르는 동안 송신, 한 번 눌러 켜고 다시 눌러 끄기도 가능)
· 볼륨 아래 버튼으로 말하기
· 마지막으로 들은 사람의 콜사인·이름·지역·무전기 이름표 표시
· 채널 슬롯: 자주 쓰는 TG·개인호출을 개수 제한 없이 저장, 즐겨찾기·그룹·검색
· 번호로 채널 바꾸기, 타임슬롯 1/2 선택, 브릿지 내부 채널
· 화면이 꺼져도 수신 계속
· 글자 크기 3단계, 밝게/어둡게 화면 — 어르신도 보기 쉽게

■ 꼭 읽어 주세요
· 이 앱만으로는 쓸 수 없습니다. DVBridge 서버 주소와 포트를 운영자에게 받아야 합니다.
· 송신하려면 아마추어 무선국 허가(콜사인)와 DMR ID가 필요합니다.
· 음성 변환은 서버가 하므로 앱에 보코더가 들어 있지 않습니다.

■ 개인정보
입력한 콜사인·이름 등은 사용자가 지정한 DVBridge 서버에만 보내며, 광고·분석 기능이 없습니다.

# Play Console 체크리스트

## 개발자 계정
- [ ] Google Play 개발자 계정 (개인, 등록비 25달러, 신분 확인)
- [ ] **새 개인 계정은 프로덕션 전에 비공개 테스트 필수**: 테스터 **12명 이상**이 **14일 연속** 참여해야 프로덕션 출시 신청 가능

## 앱 서명
- [ ] **Play 앱 서명** 사용 (기본값). 지금 서명 키(`release.jks`, 저장소에 없음)는 **업로드 키**가 됨 — 따로 안전하게 백업
- [ ] 첫 업로드는 `.aab` 파일

## 앱 콘텐츠 (정책)
- [ ] **개인정보처리방침 URL**: `https://github.com/seunghunchoi-dev/dvbridge-client-android/blob/main/PRIVACY.md`
- [ ] **데이터 보안** 양식
  - 수집: *오디오 → 음성 녹음* (앱 기능 — 말하기에 필요), *개인 정보 → 이름*, *기기 또는 기타 ID: 없음*
  - "사용자가 지정한 서버로 전송" → Google 기준으로는 **공유 아님**(사용자가 시작한 전송), **수집함**으로 표시
  - 전송 중 암호화: **아니요** (아마추어 무선 USRP는 암호화 불가·법상 공개 통신)
  - 삭제 요청: 데이터는 기기에 저장되고 앱 삭제 시 지워짐
- [ ] **포그라운드 서비스 권한 선언**: `FOREGROUND_SERVICE_MICROPHONE`, `FOREGROUND_SERVICE_MEDIA_PLAYBACK`
  - 용도 설명: "화면이 꺼진 상태에서도 무전 수신 음성을 재생하고, 사용자가 말하기 버튼을 누른 동안 송신하기 위해"
  - **시연 영상 링크** 필요 (YouTube 일부 공개 등): 앱 연결 → 화면 끈 상태에서 수신 소리 → 알림 표시
- [ ] 광고 포함: **아니요**
- [ ] 콘텐츠 등급 설문 (사용자 간 소통 기능 있음: 음성)
- [ ] 타겟층: 만 18세 이상 (또는 13세 이상) — 아동 대상 아님
- [ ] 정부 앱/금융/건강: 해당 없음
- [ ] 뉴스 앱: 아님

## 기술 요건 (이 저장소에서 확인함)
- [x] targetSdk 36 (2026-08-31부터 새 앱·업데이트 필수)
- [x] 64비트 포함 (arm64-v8a, x86_64)
- [x] 16KB 메모리 페이지: 네이티브 라이브러리(`libandroidx.graphics.path.so`) LOAD 정렬 0x4000 확인
- [x] 앱 고유 이름 `io.github.seunghunchoidev.dvbridgeclient` (출시 후 변경 불가)
- [x] 백업 끔(`allowBackup=false`), 광고·분석 SDK 없음
